# 需要的样本（放到 `research_src/`）

`research_src/` 已在 `.gitignore` 里：**里面的东西不会被提交、不会上 GitHub**。这些样本含学生姓名与学号，只当本地输入用，我也不会把里面的内容抄进任何进版本库的文档。

只要**一份作业**的量就够。按重要性排序：

## ① 成绩导出文件（最重要）

入口：学习通 →【作业】→ 找到对应作业 →【批阅】→ 右上角【导出成绩】。

- **原样给我，不要改**：包括未交、未批的学生行。
- `xls` / `xlsx` / `csv` 都行，文件名随便。
- 有了它我才能确定：哪几列是分数列、哪些列是只读的（姓名/学号/院系）、表头在第几行、学习通认不认追加列。

## ② 作答明细（判分要读的输入）

先试接口这条路，拿不到再退回 HTML：

- **接口**：打开某个学生的批阅页（或切到「按题批阅」），按 F12 → Network → 找到返回作答内容的那条请求 → 右键另存/复制为 HAR，或者把**请求 URL + 响应正文**存成文件。
- **HTML**：F12 → Elements 里确认作答已经在页面上，然后 Ctrl+S 另存为「网页，全部」。
- 顺便记一笔：这个页面**要不要额外的签名参数**（URL 里除了 `courseId`/`classId`/`workId` 之类还有没有 `enc`、`sign`、时间戳之类看不懂的东西）—— 有的话我就知道网页端也要签名，方案要改。

## ③ 手工改过并成功导入的文件（可选，但很值）

如果你以前手工改分后【导入成绩】成功过，把那份给我。对比 ① 我能立刻分清哪些列写了会被学习通接受、哪些会被拒。

## ④ 顺手的话：给我登录态，我自己去读

不想一个个导也行：浏览器登录学习通后，F12 → Network → 任意一条 mooc1 / x.chaoxing.com 的请求 → 复制整个 **Cookie 请求头**，贴给我。

拿到它我就能直接读出：**你有哪些课程、每门课几个班、每班多少人、有几份作业、每份作业的题型构成** —— 也就是你上次说的「连上学习通就知道了」的那件事。我只做只读 + 限速的 GET，不提交、不改分、不登录。
