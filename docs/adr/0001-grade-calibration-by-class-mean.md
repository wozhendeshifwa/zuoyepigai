# 调分按班级均分统一平移，不用「调主观题评分去凑」的办法

## Status

accepted

## 背景与决定

批改结束后，如果某个班的**均分**落在目标均分 92 的 ±1 之外，程序给该班**全班**的作业得分加同一个偏移量，把班级均分拉回区间内；本来就落在区间里就一分不动。这是**软目标**：不追求精确等于 92。

配套的四条口径一起定下：

- **作用层**：调的是**每次作业的班级均分**。课程层面的综合成绩由学习通按权重自己算，程序不碰。
- **谁参与均分**：只统计「已交且已批」的学生。未交、未批的行在原文件里原样保留，不参与统计（另一口径的数字只做参考报出，不影响调分）。
- **原始分留档**：原始分与调分后的得分一起留，任何一次调分都能还原。
- **主观题评分不参与凑数**：主观题一律按参考答案或评分要点正常判，不为了让均分好看而松紧。

## Considered Options

- **调 AI 判主观题的松紧去凑均分**：分数看起来更「自然」，但同一份作答的分数会随班级整体水平漂移，AI 写的评语会和分数对不上；而且判分不可复现——同一份作业在 A 班 92、换到 B 班就不是了。**否掉**。
- **调课程综合成绩**：单次作业的成绩单上均分仍然难看；而且综合成绩是学习通按权重算出来的，改它等于和平台抢同一块地。**否掉**。
- **不调分，只报原始分**：这是最干净的做法，但需求本身就是控制班级均分，不是拿原始分。**否掉**。

## Consequences

- 平移不改变名次：学生之间谁高谁低不受影响。
- 得分的有效区间由课程惯例给定：**最高 98、最低 75**，不出现 100 分。封顶与保底在平移之后一起生效，所以最终分数永远落在这 22 分区间内；平移因此不可能把人推到 0 或 100。
- 这个区间只作用于**已交**的学生。未交的人保持 0 或空白，不会被抬到 75——否则「不交作业」与「交了但答得很差」就分不出来了。
- 成绩单上会出现「加过分的分」，所以原始分必须和调分后的分一起留档，否则事后无法回答「这个分是怎么来的」。
- 调分是最后一步：AI 判分 → 人工复核（改的是原始分）→ 调分 → 出成绩导入文件。复核改完再调分，不会出现「调完分又被人改分」的错位。
